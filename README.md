🌱 LANSAKIU — A Little World

Un pequeño jardín, infinitos momentos por descubrir. ♡

LANSAKIU es un proyecto personal desarrollado con HTML, CSS, JavaScript y Three.js, que combina un jardín tridimensional interactivo con una experiencia relajante, llena de vida y pequeños secretos.

Conoce a LANSAKIU, un adorable lanzaguisantes que reacciona a tus interacciones, observa cómo cambia el paisaje con el paso del tiempo, descubre fenómenos extraordinarios y crea tus propios recuerdos.

El jardín cuenta con ciclos de día y noche, estaciones, clima dinámico, animales visitantes, personalización, fotografía, cartas, calendario y acontecimientos ocultos.

No hay prisa, objetivos obligatorios ni necesidad de competir. Solo tú, LANSAKIU y un pequeño mundo al que siempre puedes regresar.
